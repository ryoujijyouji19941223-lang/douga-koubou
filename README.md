# 動画工房

AIとの会話を、2人の掛け合い動画にする道具。Windows用。

## ダウンロード

右上の緑の「Code」→「Download ZIP」。ZIPを開いたら、中の **はじめに読んでな.txt** から。

## できること

- 台本（`名前「セリフ」` を1行ずつ並べた文字のファイル）から、声・字幕・絵付きの動画を作る
- 声は VOICEVOX（無料の読み上げソフト）が自動で付ける
- 自分の声を録ったファイルを入れたら、その行だけ自分の声に差し替わる
- キャラの絵と背景は「絵」フォルダに入れるだけ

## 使い方

1. VOICEVOX を入れる：https://voicevox.hiroshiba.jp/
2. 「はじめに一回だけ.bat」をダブルクリック（最初だけ）
3. VOICEVOX を開いたまま「動画を作る.bat」をダブルクリック
4. 「できた動画」フォルダに動画が出る

直したいときは、`台本.txt` を書き換えてもう一回ダブルクリック。

## 台本工房.html

会話を貼って台本の形に直す画面。ブラウザで開くと、手で台本を書いてコピーできる。
（AIで自動で台本にするボタンは、Claude の上で開いたときだけ動く）

## 投稿するとき

`できた動画/説明欄に貼る文.txt` の中身を、動画の説明欄に貼る（VOICEVOX の決まり）。
