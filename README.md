# douga-koubou

ととまるの動画・配信づくりの道具箱。Windows用。

**作りたいものの話は → [構想.md](構想.md)**

## 中身

| フォルダ | できること |
|---|---|
| [動画工房](動画工房/) | AIとの会話の台本から、声・字幕・絵付きの掛け合い動画を作る。AIのセリフを聞きながら自分の声を録る録音スタジオつき |
| [配信工房](配信工房/) | アバター付きで、雑談を録る・雑談配信・ゲーム配信をする |

どっちも、フォルダの中の **はじめに読んでな.txt** から始める。

## ダウンロード

右上の緑の「Code」→「Download ZIP」。ZIPを開いて、使いたいフォルダを好きな場所に置く。

## 使っている無料ソフト

- [VOICEVOX](https://voicevox.hiroshiba.jp/)（読み上げの声）… 動画工房
- [OBS Studio](https://obsproject.com/ja)（配信・録画）… 配信工房
- 3Dにするなら [VRoid Studio](https://vroid.com/studio) と [VSeeFace](https://www.vseeface.icu/)

動画を投稿するときは、VOICEVOX の声の名前を説明欄に書く（動画工房が「説明欄に貼る文.txt」を作る）。
