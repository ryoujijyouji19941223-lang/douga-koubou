配信工房 ― 雑談の録画、雑談配信、ゲーム配信をアバター付きでやる道具

■ 最初に一回だけ
1. 「はじめに一回だけ.bat」をダブルクリック
   → 配信・録画のソフト「OBS」が入る
2. 「もう一回」と出たら、閉じてもう一回ダブルクリック
   → OBS が一回開く。最初の質問は「録画のために最適化」→「次へ」で進めて、終わったら OBS を閉じる
3. もう一回ダブルクリック → 「準備できた！」と出たら終わり

■ 雑談動画を録る
1. 「雑談を録る.bat」をダブルクリック → OBS が開いて、すぐ録画が始まる
2. しゃべる。声に合わせてアバターの口が動く
3. 終わったら OBS の右下「録画終了」を押す
4. 「録画」フォルダに動画ができてる

■ 配信する（雑談・ゲーム）
1. 最初だけ：OBS の「設定」→「配信」で YouTube などにログインする
2. 「OBSを開く.bat」をダブルクリック
3. 左下の「シーン」で画面を選ぶ
   ・待機中 … 「もうすぐ始まるで」の画面
   ・雑談   … 背景＋大きいアバター
   ・ゲーム … ゲーム画面＋右下に小さいアバター
   ・おわり … 「ありがとう、またな」の画面
4. 右下の「配信開始」を押す。終わったら「配信終了」
   （ゲームは先に起動しておく。映らんときは「ゲーム画面（ウィンドウ）」の目のマークを押して、ゲームを選ぶ）

■ 変えたいとき
・アバターの絵 → 「アバター」フォルダに 通常.png と 口開き.png を入れる（中の説明を見てな）
・口が動かん／動きすぎる → 「画面の設定.js」の「感度」を変える
・画面の上に出る題名 → 「タイトル.txt」を書き換えて保存（OBS を開いたままでも変わる）
・待機中・おわりの文字 → 「画面の設定.js」
・雑談の背景 → 「背景」フォルダに 背景.png を入れる
・アバターのお試し → 「アバター.html」をダブルクリック →「マイクで試す」

■ 3Dのアバターを使いたくなったら（あとでええ）
1. VRoid Studio（無料）で3Dのキャラを作る：https://vroid.com/studio
2. VSeeFace（無料）でそのキャラを開く。カメラで顔の動きをまねしてくれる：https://www.vseeface.icu/
   VSeeFace の設定で「背景を透明にする」をオンにする
3. OBS の「3Dアバター（VSeeFace）」の目のマークを押して表示、「アバター」の目のマークを押して隠す

■ うまくいかんとき
・アバターの口が動かず「OBSとつながってへん」と出る
  → OBS の「ツール」→「WebSocketサーバー設定」で「WebSocketサーバーを有効にする」にチェック
    「認証を有効にする」のチェックは外す →「OK」
・このフォルダを別の場所に動かした → 「はじめに一回だけ.bat」をもう一回
・それでもあかん → 出たメッセージや画面を Claude に見せる
